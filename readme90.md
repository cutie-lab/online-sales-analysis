# Sales Data Analysis Using MySQL Workbench and Power BI

## Project Overview

This project focuses on analyzing sales data using MySQL Workbench and Power BI. The objective is to organize sales data, perform data analysis, and create interactive visualizations to understand sales performance.

## Tools Used

* MySQL Workbench
* Microsoft Power BI
* SQL

## Project Objectives

* Store and manage sales data using MySQL.
* Retrieve and analyze data using SQL queries.
* Identify top-selling products.
* Compare sales across categories.
* Calculate average sales per product.
* Analyze customer sales and regional performance.
* Create interactive dashboards in Power BI.

## Project Workflow

### Step 1: Data Management Using MySQL Workbench

* Create and manage the sales database.
* Store sales and customer information in tables.
* Retrieve relevant information using SQL queries.
* Filter, group, and summarize sales data.

### Step 2: Data Visualization Using Power BI

* Connect the sales data to Power BI.
* Create product-wise sales reports.
* Identify top-selling products.
* Compare sales across categories.
* Display average sales per product.
* Create charts, tables, and interactive slicers.

## Key Analysis

* Product-wise sales analysis
* Top-selling product identification
* Category-wise sales comparison
* Average sales per product
* Customer sales analysis
* Regional sales visualization
